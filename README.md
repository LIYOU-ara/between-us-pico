# Between Us

面向面对面交流的 PICO MR 交互原型。应用提供语音转写、基于实际台词的交流建议，以及经单独同意启用的单帧面部裁剪分析。

## 项目与构建

- Unity：`6000.6.4f1`；PICO Integration：`3.4.0`。
- 显示名称：`Between Us`；版本：`1.0`；Android versionCode：`1`。
- 包名：`com.prototype.pico.conversation`。
- Android：ARM64、IL2CPP、OpenGLES3，最低 API 29，目标 API 自动选择。
- 唯一启用的入口场景：`Assets/Prototype/PicoConversation.unity`。标准云构建使用此场景，无需运行场景生成工具。

## 首次运行与操作

应用不内置 API Key。首次运行打开 API 设置，输入自己的智谱 API Key 后点击“应用（仅本次）”。密钥只显示掩码；系统键盘不可用时，可在 Windows 上运行本仓库的 `Configure-Pico-Conversation.cmd`，通过 USB 和头显显示的六位配对码录入。电脑需自行安装 Android Platform Tools 并将 ADB 加入 PATH；辅助工具不会保存 Key。

| 操作 | 按键 |
| --- | --- |
| 开始交流／从错误恢复 | 左手 X |
| 结束交流并请求总结 | 右手 A |
| 暂停／恢复采集；总结时翻页 | 右手 B |
| 打开／关闭 API 设置 | 左手 Y |
| 在 API 设置中选择按钮 | 任一手柄扳机 |

设置还实现了无手柄注视选择和独立确认／取消。设置可在空闲、总结完成或处理停止的错误状态修改；正在交流或处理请求时锁定。Key 错误时可按 Y 更正。应用新配置会清除当前交流记录。

## 同意与隐私

开始前应征得所有参与者对语音／文本云处理的同意。语音转写和文本建议使用智谱云服务；单帧面部裁剪上传须另行勾选同意，默认关闭。关闭上传仍会使用本地相机进行面部定位与画面处理。应用请求相机、麦克风和网络权限。

Key 只保留在本次应用进程内，不写入项目或存档；退出应用后清除。关闭设置会丢弃未应用的输入；清除 Key 会同时关闭视觉上传。原始相机数据和可选云端面部裁剪的用途不同，不应将关闭云端上传理解为关闭相机访问。

## 验证范围

代码目标设备为 PICO 4 Ultra，设备提示为 OS 5.15+。这不是跨设备兼容承诺；PICO OS 6、Space Pro 和其他设备尚未由本发布副本确认。当前使用 PXR 沉浸式 MR 与透视背景，未声明已完成 Unity Spatial 或系统多窗口适配。

本副本已做静态场景、配置及运行时设置入口检查，尚未执行云构建、安装或头显验收。原生键盘、手柄射线、注视确认、相机权限和云服务连通性需在目标设备验证。
